# Assets locais opcionais

Coloque aqui apenas arquivos que você tem direito de usar. O aplicativo nunca baixa
SFX, memes ou overlays automaticamente.

- `sfx/`: efeitos sonoros próprios para associações futuras a eventos.
- `memes/`: imagens ou vídeos locais escolhidos manualmente em revisões futuras.
- `overlays/`: elementos gráficos locais.
- `fonts/`: fontes opcionais licenciadas para legendas e textos.

Os diretórios são mantidos no Git apenas com arquivos `.gitkeep`; não coloque mídia
grande no repositório.
