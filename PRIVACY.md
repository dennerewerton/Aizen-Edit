# Política de Privacidade — Aizen Auto Editor

Última atualização: 15 de agosto de 2026

O Aizen Auto Editor é um editor de vídeo para Windows. Ele foi projetado para analisar e editar vídeos no computador do usuário.

## Dados tratados localmente

Os vídeos escolhidos, áudios extraídos, transcrições, projetos e arquivos de edição são processados e armazenados localmente no computador do usuário. Esses dados não são enviados pelo Aizen Auto Editor para servidores próprios.

## Conexões com a internet

O aplicativo pode acessar o GitHub para verificar e baixar atualizações quando utilizado fora da Microsoft Store. A versão distribuída pela Microsoft Store utiliza o mecanismo de atualização da própria Store. O uso de recursos opcionais configurados pelo usuário, como serviços externos de transcrição, depende das configurações e políticas desses serviços.

## Compartilhamento de dados

O Aizen Auto Editor não vende, não aluga e não compartilha os arquivos de vídeo ou projetos locais do usuário com terceiros.

## Segurança

Os arquivos originais não são modificados. O aplicativo cria cópias e projetos separados para a edição.
